LogSentinel

Nginx / Apache 存取日誌威脅偵測工具

輸入一份 access log,自動找出攻擊行為並產出可互動的 HTML 報告,不需資料庫或第三方服務。

  • 偵測 SQLi、XSS、路徑遍歷、指令注入、敏感檔案存取、惡意掃描工具與暴力破解
  • 複合攻擊標記:單一請求命中多種特徵時提高該 IP 威脅分數
  • 時間窗口掃描偵測(雙指標,O(n log n)),規則集中於 rules.py 可擴充
  • pytest 單元測試與 GitHub Actions CI
